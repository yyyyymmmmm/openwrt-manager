# 架构 Architecture

> 来源：目标工作区 `briefs/structure-spec-v1.md`（结构规格 v1，2026-11-20 定版）精要收编，2026-11-21。
> 与代码冲突时以代码为准；本篇只记耐久结构，不记过程进度。

## 全原生红线

App 管理的是 OpenWrt 本身：每个功能、每个界面都在手机 App 内原生实现、原生操作。禁止用 WebView 内嵌 LuCI、点按钮跳浏览器/打开网址、或以「去电脑上操作」充当功能实现。可行性依据：LuCI 本身只是一个前端，其全部数据与动作都走 ubus JSON-RPC / UCI / rpcd 文件接口，原生 App 用同一套接口即可全量复刻。终端的原生等价物是 SSH 协议客户端，文件管理走 ubus file 接口——两者在原生版落地前宁可不出现，也不许放网页入口。

## 五层地基

页面只许建在地基之上，0 期地基验收后才许建页面。

| 层 | 内容 | 关键口径 |
|---|---|---|
| L0 连接层 | 多路由器档案（名称/地址候选/备注）；连通性探测与地址自动切换 | 断网有明确错误态 |
| L1 会话层 | LuCI 表单登录（sysauth → ubus session）、令牌生命周期、过期自动重登、凭据存 Keychain | 必须走 LuCI HTTP 表单登录取 `sysauth_http` cookie；裸 ubus session login 不写 LuCI 的 `values.token`，菜单会残缺（热修一轮实证） |
| L2 发现层 | 连接后枚举固件版本、机型、真实菜单树、已装服务清单、接口清单，生成 CapabilitySnapshot（带时间戳、按路由器缓存） | 快照须与设备实查菜单树逐项对得上 |
| L3 数据层 | ubus 客户端、UCI 只读客户端、实时轮询引擎（全 App 共用一个节拍）、数据新鲜度标记、离线只读缓存 | 同一数据全 App 单一来源；过期数据必带「已过期」标记，不冒充实时 |
| L4 事务层 | 写操作统一通道，见下 | 任何页面不许绕过它直写 UCI |

事务层（唯一写门 `RouterStore.executeConfiguration`）：改前快照 → 差异预览 → 用户确认 → 下发 → 服务重载 → 回读验证 → 失败回滚。

公用件：状态卡、列表行、空状态、错误态、折叠组、实时图表、确认弹窗由公用件提供，页面只组装、不自造同类组件。间距/字阶/颜色全走设计令牌。

## 导航结构

五 Tab，权重决定施工顺序与首页资源位：

| Tab | 承接 | 权重 |
|---|---|---|
| 概览 | 路由器「状态」分组 | P0（默认落地页） |
| 网络 | 路由器「网络」分组 | P0 |
| 服务 | 路由器「服务」分组 | P0 |
| 系统 | 路由器「系统」分组 | P2 |
| 设置 | App 自身（档案、外观、诊断、关于） | P2 |

导航只由「发现快照 + 专用页注册表」（`PageRegistry`）生成：设备上没有的菜单不显示（如无无线则不显示无线页）；注册表里没有的服务走结构化 UCI 通用页兜底并明示「通用页」；绝不假造入口。新页面准入四问：有没有入口、有没有重复、走不走令牌与公用件、最大字号与深色各验一帧。

服务页构成 = 发现层菜单条目 ∩ init.d 服务状态（在跑/停/自启），绝不用软件包目录冒充服务清单。专用页分级：P0 为 Open-Box / HomeProxy / MosDNS；P1 为动态 DNS、ZeroTier、frpc、NATMap、Socat、WebDAV、网络唤醒、KMS；其余走通用页。

上游口径：上游接口由发现层判定，不许写死查 `wan`（旁路由实走 br-lan，wan/wan6 设备不存在）。

## 双机差异（发现层要吃下的实况，2026-11-20 实查）

| | 旁路由 .167 | 主路由 .1 |
|---|---|---|
| 版本 | OpenWrt 25.12.5 | OpenWrt 24.10.8（AX3000T） |
| 二级菜单 | 47 个 | 24 个 |
| 无线 | 无（菜单不存在） | 有（双频在跑） |
| 服务来源 | LuCI 服务应用 14 项 | LuCI 服务组为空，由 init.d 核心服务 26 项填充 |
| DHCP/DNS | 独立菜单 | 合并菜单 |
| 上游 | br-lan（wan/wan6 不存在） | loopback/lan/wan/wan6 均有定义 |

## 分期（已全部交付）

- 0 期：L0–L3 地基 + 发现快照与双机实查树对位。
- 1 期：五 Tab 只读全覆盖 + 公用件 + 令牌。
- 2 期：事务层启用写操作（服务、防火墙、DHCP、接口编辑、重启类）。
- 3 期：原生终端、文件管理、在线升级（加强事务：自动备份 → 哈希校验 → 二次确认 → 升级 → 自动重连验证）。

后续增量以「包」为单位交付（诊断导出、备份恢复、主题系统、权限修复等），里程碑见 [../CHANGELOG.md](../CHANGELOG.md)。
