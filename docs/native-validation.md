# 原生逐层验证范围

本轮继续现有原生实现，使用正常 HTTP 登录和请求路径验证。测试数据仅由 CI 主机环回服务器提供，不编入正式 App。测试定义存在不代表已经通过；执行证据以 TASKS.md 和对应 GitHub Actions 为准。

所有测试字段都会打开值编辑器并检查字段名称不可重命名，再取消返回。该断言仅适用于测试固件返回的字符串/列表；真实路由器的每个动态字段仍需逐项验收。

## 协议与发布检查

- OpenWrtKit：概览、租约、无线、服务、配置事务、软件包、记录及地址解析回归；路由只发四个固定 `/sbin/ip` 请求，ACL/退出码/格式错误会传播。
- Python：6 项发布审计规则，4 项 HTTP 服务器协议测试。服务器会话独立；只读不能写配置或控制服务；回滚恢复实际服务器状态。
- Release：XcodeGen 生成工程，Xcode 26 编译 iPhone ARM64，未签名 IPA 审计禁止测试数据、测试资源和签名材料。

## 尚未覆盖或完成

- 全部真实固件、所有 LuCI 菜单和插件专有接口的逐项映射；通用 UCI 字段编辑不等于专用表单。
- 真实路由器写入、网络中断后的恢复、全部插件专有流程、软件包安装升级卸载、备份恢复、固件升级。
- 实体 iPhone 的局域网权限、证书变化、发现扫描实际结果、系统设置跳转和系统分享面板。
- 新增匿名节、空列表、敏感字段显示/隐藏及配置超时回滚的 UI 自动化尚待补齐；协议事务已有独立回归。
- 多路由器切换完成登录、保存记录删除和异常刷新后的旧数据保留仍需专项 UI 验收。

当前路由表查询默认只显示主路由表，不覆盖全部策略表或多路径输出；命令或响应不兼容会显示错误。邻居表不是持续在线检测。
